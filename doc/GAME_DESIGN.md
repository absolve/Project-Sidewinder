## 1. 概述

| 项 | 内容 |
|---|---|
| 项目名 | Project-Sidewinder |
| 类型 | 俯视角载具射击 × 夺械改装 × 多模式 |
| 视角 | 俯视 / 等距 2D |
| 操作 | WASD 移动 + 鼠标瞄准（双摇杆）；手柄双摇杆；可选自动瞄准辅助 |
| 引擎 | Godot 4.x（GDScript / C#） |
| 目标平台 | PC（Steam），优先适配 Steam Deck 与手柄，简中首发 |
| 游戏模式 | **故事模式（战役通关） / 任务模式（多区域目标探索） / 割草模式（波次生存）** |
| 美术方向 | 待定（候选：像素 / 风格化 2D / 低多边形 3D 俯视） |

### 一句话卖点

> 驾驶可改装的战斗载具，**从被击毁的敌人身上夺取武器、装配到自己的硬点上**；在多区域战场里自由探索、完成歼灭/夺取/防守/采集目标，轰开地形挖出资源与秘密，并在割草潮中构筑流派活到最后。

### 设计目标

1. **玩法要新**：以「夺械改装 + 多区域目标探索 + 破坏采集」组合出区别于市面割草/坦克游戏的独特循环。
2. **博采众长**：有选择地融合其他游戏的成熟机制（见 §8 借鉴来源），但用统一的载具改装与探索系统把它们串成一个整体。
3. **一套系统、三种玩法**：故事/任务/割草三模式共享载具、武器、成长系统，开发成本可控、体验互相补强。

## 2. 核心创新点（让玩法「新」的关键）

1. **夺械改装（Weapon Salvage）**
   武器主要不是「买」来的，而是**从被击毁的敌人身上夺取**、或从地图武器箱/秘密区搜刮来的。不同敌人携带不同武器，击毁即可拾取装配。→ **战斗 = 刷装备 = 探索动力**，把「射击」与「刷宝」深度绑定。

2. **模块化硬点 + 重量/能量预算**
   载具有有限的**硬点（挂载槽）**，每件武器有重量/能耗/弹药类型；装配受预算约束，取舍构成构筑深度。缴获的武器可临时用、也可带回永久入库。

3. **多区域目标制任务地图**
   任务模式用**固定手工地图**，划分为多个可自由探索的**区域**；每关有主目标 + 多个次目标/可选区域（歼灭、夺取、防守、采集、撤离）。玩家自选路线与目标顺序，可选区域藏秘密、稀有武器与资源。

4. **破坏即探索 / 采集**
   轰开墙体/油桶/矿脉不只是战斗特效，更是**开捷径、揭秘密、挖资源**的探索手段；战争迷雾随探索揭开，引导找目标。

5. **基地防守作为关卡目标（按关卡组合）**
   采集资源、保护基地/发电机不是独立玩法，而是**在不同关卡里作为目标模块出现**：有的关要守基地抗波次 + 建炮塔，有的关要采集够资源再撤离，组合变化。

6. **三模式共享进度**
   武器库、载具底盘、天赋、货币材料跨模式共用；在任务模式缴获的稀有武器可带进割草模式，割草解锁的天赋反哺故事战役。

## 3. 三大游戏模式

### 3.1 故事模式（战役通关）

- **定位**：线性叙事战役，带玩家上手并展开世界观。
- **结构**：章节制推进，每章若干关卡；关卡含剧情节点、强制目标与递进难度；通关解锁结局与奖励。
- **关卡形态**：复用任务式地图，但目标更线性、有脚本演出与 Boss 高潮。
- **重玩**：章节选择 + 多难度 + 三星评分 + 隐藏收集。
- **待补充**：章节大纲、剧情节点、关卡列表、Boss 设计。

### 3.2 任务模式（多区域目标探索）—— 创新核心

- **定位**：独立的目标制探索关卡，是「夺械 + 探索 + 破坏采集 + 防守」集中体现的模式。
- **地图**：**固定手工地图**，每关由**多个区域**组成（如废墟区/工业区/矿区/基地核心区），区域间有通道、可破坏捷径与秘密路径；玩家自由探索不同区域。
- **通关条件（目标制，按关组合）**：
  - **歼灭**：清空某区域敌人 / 击毁精英 / 摧毁生成器。
  - **夺取**：取得指定物品 / 打开武器箱 / 缴获敌方原型武器。
  - **防守**：保护基地/发电机抵御若干波次，可建炮塔工事。
  - **采集**：挖够指定资源 / 占领采集中继点。
  - **撤离**：带着战利品抵达撤离点（可选「提取」风险收益）。
  - 每关 = 1 个主目标 + 多个次目标/可选区域；完成主目标即可通关，次目标给额外奖励与评分。
- **武器来源**：
  - **击败敌人收集对方武器**（不同敌人掉不同武器，精英/Boss 掉稀有武器）。
  - **地图武器箱**：散布各区域，含随机/稀有武器与改装件。
  - **秘密区**：隐藏区域藏高级战利品，需破坏/探索发现。
- **资源采集 + 基地防守**：作为目标模块在不同关卡灵活组合（例：A 关「采集 X 资源并守住基地 3 波」；B 关「歼灭三区敌人并夺取原型武器」）。
- **重玩**：刷稀有武器/改装件 + 次目标全清 + 评分排行榜 + 随机战利品词缀。
- **待补充**：区域地图规范、目标类型规则、战利品/武器箱掉落表、警戒增援规则、撤离机制。

### 3.3 割草模式（波次生存）

- **定位**：Survivors-like 爽快割草，短局高重玩，验证构筑深度。
- **结构**：程序生成战场（或固定竞技场），波次压力递增 + 精英/Boss；单局 10–15 分钟。
- **构筑**：局内升级三选一（武器词条/性能/模块）+ 波间商店买卖与同级武器合成；可用任务模式缴获的武器入库。
- **操作**：手动瞄准为主，可选自动瞄准辅助（降低门槛）。
- **重玩**：冲分 + 全球排行榜 + 每日固定种子挑战 + 难度阶梯换奖励。
- **待补充**：波次曲线、升级池、合成规则、排行榜/种子规则。

### 3.4 模式间共享进度

- **共享**：武器库、载具底盘、模块/天赋、货币与材料、解锁进度。
- **差异**：故事=线性叙事；任务=手工地图自由探索刷宝；割草=程序生成波次构筑。
- **经济统一**：缴获/采集/击杀所得资源进入统一账户，用于改装与解锁。

## 4. 共享核心系统

### 4.1 载具模块化改装 + 夺械
- 载具分 **底盘 / 硬点（武器槽）/ 模块** 三类槽位；硬点有数量与重量/能量预算。
- 武器从敌人/武器箱/秘密区缴获；可临时装配使用，或带回永久入库。
- 模块提供被动协同（如「弹药回收」「过热减免」「采集加成」「炮塔强化」），槽位间互锁产生流派。
- 待补充：底盘清单、硬点/预算规则、模块清单、协同规则。

### 4.2 武器系统（稀有度 / 词缀 / 元素 / 弹道）
- 武器有**稀有度 + 随机词缀**（刷宝深度），元素/弹道语义：火焰灼烧、闪电链、冰冻控场、火箭追踪、穿透轨道、霰弹散射、反弹蓄力等。
- 武器有弹药类型与上限；空弹自动切换备用武器。
- 待补充：武器清单、稀有度/词缀池、元素反应、数值表。

### 4.3 破坏 / 采集 / 探索
- 可破坏物：墙体（开捷径）、油桶（连锁爆炸）、矿脉（掉资源）、秘密墙（藏奖励）、武器箱。
- 战争迷雾随探索揭开；采集资源接入统一经济。
- 待补充：可破坏物类型、掉落表、迷雾规则、矿脉/秘密分布。

### 4.4 基地防守 / 建造
- 部分关卡/区域需守基地或发电机抗波次；可建炮塔与防御工事。
- 基地被毁 = 失败（或次目标扣分）；提供防守压力与建造策略。
- 待补充：基地结构、建造槽、炮塔类型、波次进攻规则。

### 4.5 弹药 / 装填 / 过热
- 弹药有限，需采集/缴获/购买补充；装填/过热做成有节奏的技巧机制。
- 硬点装载位有限，武器取舍即战术。
- 待补充：弹药上限、装填/过热曲线、装载位规则。

### 4.6 成长与经济
- **局内**：升级三选一（词条/性能/模块）。
- **波间/关间**：商店买卖 + 同级武器合成升阶 + 改装载具。
- **局外**：永久解锁底盘/武器/天赋/模块；难度阶梯换奖励；三模式共享。
- 待补充：货币体系、价格表、解锁树、难度系数。

### 4.7 敌人 / 精英 / Boss / 警戒增援
- 多种敌人携带不同武器（夺械来源）；精英/Boss 掉稀有武器。
- 敌人有感知/追击/警戒链；清区域或开枪可触发**增援**，鼓励潜行 vs 强攻的路线选择。
- 生成器持续刷怪，可优先摧毁减压。
- 待补充：敌人清单、携带武器表、AI 行为、警戒/增援规则、Boss 机制。

## 5. 关卡设计（多区域任务地图）

- **区域划分**：每关 3–6 个区域，各有主题、敌人配置、目标点、武器箱、资源点。
- **连接与捷径**：区域间主通道 + 可破坏捷径 + 秘密路径；鼓励探索与路线规划。
- **目标点**：主目标（必做）+ 次目标/可选区域（额外奖励）；基地/撤离点作为防守/提取目标。
- **战利品分布**：敌人携械 + 武器箱 + 秘密区稀有掉落，驱动探索。
- **警戒与增援**：区域警戒等级随战斗上升，触发增援；潜行/强攻产生不同节奏。
- **生成方式**：故事/任务=手工地图；割草=程序生成。
- 待补充：地图编辑规范、区域模板、目标/战利品配置工具、评分规则。

## 7. 技术方案

- 引擎：Godot 4.x；GDScript 为主，性能热点（寻路/大量实体）可用 C#。
- 工程目录：`Project-Sidewinder/`（Godot 工程）。
- 架构：模块化系统（载具/武器/敌人/关卡/目标/经济/UI），信号 + 明确 API 协作；静态配置与运行时状态分离；**目标系统做成可组合模块以复用三模式**。
- 适配：手柄 + Steam Deck；简中首发。
- 待补充：场景/脚本目录规范、物理层定义、存档方案、关卡编辑工具、性能预算。

## 8. 机制借鉴来源（融合其他游戏，非抄袭）

| 借鉴机制 | 参考游戏 | 在本项目的落地 |
|---|---|---|
| 拾取/夺取敌人武器 | RUINER、Panzer Paladin | 夺械改装核心：击毁敌人缴获其武器装配 |
| 武器拼装 / 模块化构筑 | MOTHERGUNSHIP、Nova Drift | 硬点 + 模块互锁构筑流派 |
| 装载位 / 背包管理 | God of Weapons | 硬点重量/能量预算，武器取舍 |
| 刷宝稀有度 / 词缀 | Borderlands、The Slormancer、Chronicon | 武器稀有度 + 随机词缀，重玩刷装备 |
| 目标制任务 + 战略配备 + 增援 | HELLDIVERS | 任务模式主/次目标、呼叫炮塔/空袭、警戒增援 |
| 探索密度 / 隐藏秘密 | Hyper Light Drifter | 多区域地图、秘密路径与隐藏战利品 |
| 破坏即采集 / 挖矿第二动作 | Dysmantle、DRG: Survivor、Core Keeper、Cogmind | 轰开地形挖资源、开捷径、揭秘密 |
| 基地防守 + 建造 + 波次 | The Riftbreaker、Thronefall、Dungeon of the Endless | 关卡内守基地/发电机 + 建炮塔 |
| 割草构筑循环 | Vampire Survivors、Brotato、20 Minutes Till Dawn、Rogue: Genesia | 割草模式三选一 + 波间商店 + 合成 + 手动瞄准 |
| 三星评分 / 排行榜 / 每日种子 | Geometry Wars 3、Crypt of the NecroDancer | 重玩激励与长尾留存 |
| 硬核弹药/装填/过热 | SYNTHETIK、OS Omega | 弹药经济做成技巧机制 |

> 创新在于**组合与统一**：把「夺械刷宝 + 多区域目标探索 + 破坏采集 + 基地防守 + 割草构筑」用同一套载具改装与成长系统串成三模式整体，而非简单叠加。

## 9. MVP 范围（先验证核心乐趣）

1. 载具移动/瞄准清潮 + **夺械拾取装配**（验证「战斗=刷装备」核心）。
2. **1 张多区域任务地图**：2–3 个区域 + 主/次目标（歼灭 + 夺取）+ 武器箱 + 可破坏地形掉资源 + 迷雾揭开（验证探索循环）。
3. 硬点预算 + 武器稀有度/词缀（验证构筑取舍）。
4. 1 个基地防守目标 + 1 个 Boss（验证高潮）。
5. 极致 Juice（震屏/命中停顿/粒子/夺械反馈）。
6. 简中 + 手柄 + Steam Deck 适配。

> 原则：**先做深「任务模式」的夺械+探索核心**，再扩展故事战役与割草模式。宁可做深一个机制，也别摊薄内容。
