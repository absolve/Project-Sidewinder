# Project-Sidewinder

一款俯视角载具射击游戏（Top-Down Vehicle Shooter）。玩家驾驶可改装的战斗载具，在程序生成的战场上清剿敌潮、轰开地形采集资源、改装武器与模块，并守住自己的基地。玩法融合 **双摇杆射击 + 可破坏地形采集 + 割草式构筑成长 + 基地防守**。

> 当前状态：项目搭建中（早期原型阶段）。

## 目录结构

```
Project-Sidewinder/
├── doc/                  # 设计文档（玩法、系统、关卡、数值等，持续补充）
├── Project-Sidewinder/   # Godot 工程目录
├── LICENSE               # 许可证（MIT）
└── README.md             # 本文件
```

## 技术栈

- 引擎：Godot 4.x
- 语言：GDScript / C#
- 目标平台：PC（Steam），优先适配 Steam Deck 与手柄

## 开发约定

- 设计文档统一放在 `doc/`，Godot 工程资源统一放在 `Project-Sidewinder/`。
- 文档使用 UTF-8 Markdown，建议用支持 UTF-8 的阅读器查看。
